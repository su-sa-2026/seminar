This notebook (clip_model_colab_reduced.ipynb) implements a deep learning pipeline that takes multimodal inputs (images paired with text, such as memes) and classifies their sentiment into 2 classes (positive vs. non_positive). It is adapted for Google Colab with **fewer labels and subsampled data so experiments run quickly**.
